AltHub — менеджер аккаунтов Roblox
==================================

КАК ЗАПУСТИТЬ
  AltHub 1.5.0 — финальный выпуск 1.5: центр запуска, сценарии и три меню.
  Скачать: https://github.com/ErnestKostevich/AltHub/releases/tag/v1.5.0
  Нужен AltHub-1.5.0.zip. Файл .sha256.txt — контрольная сумма, не программа.
  Исторический предварительный v1.5.0-rc1 сохранён отдельно.
  1. Распакуй архив ЦЕЛИКОМ в любую папку (не запускай прямо из архива).
  2. Дважды щёлкни «Запустить AltHub.cmd».
  3. Хочешь значок на рабочем столе — «Ярлык на рабочий стол.cmd».

КАК ОБНОВИТЬ
  Закрой AltHub. Распакуй новую версию в отдельную папку и скопируй туда
  папку data из старой версии. Старую папку сохрани как резервную копию.
  При DPAPI аккаунты открываются только под тем же пользователем Windows
  на том же компьютере.

ОБНОВЛЕНИЕ 23 ОКТЯБРЯ 2026
  Пересборка той же версии 1.5.0, тег v1.5.0 не меняется.
  Автораскладка выключена для новых установок и старых настроек без этой опции.
  Явно сохранённый выбор и настройки сценариев сохраняются.
  Настройки -> Окна -> «Раскладывать окна сеткой сразу после запуска»:
  выключение отменяет ожидающее перемещение. Ручная кнопка «Окна» работает.
  «Закрыть» убирает выбранные аккаунты из очереди и закрывает уже созданные
  процессы, даже пока окна нет. Присмотр и автоперезапуск не возвращают их
  до ручного запуска или перезапуска AltHub. Другие процессы Roblox не трогаются.
  Исправлено удаление локальной .ROBLOSECURITY с доменом .roblox.com.
  Перед открытием Roblox проверяется, что старая кука действительно удалена.

ВИД МЕНЮ
  Настройки -> Вид: «Dashboard», «H₂O Original» или «Pulse».
  Меняется сразу, без перезапуска. Запущенные окна Roblox не закрываются.
  В H₂O при ширине карточки до 680 точек (с учётом масштаба) запуск высокий,
  настройки и закрытие — друг над другом справа; на широких карточках — в строку.

ЯЗЫК / LANGUAGE
  На новой установке русский выбирается для русского интерфейса Windows,
  иначе English. Сохранённый выбор не меняется при обновлении.
  На первом экране мастера выбери Русский (Russian) / English — язык сменится сразу.
  Настройки -> Вид -> Язык интерфейса -> Русский (Russian) / English -> Сохранить.
  Settings -> Appearance -> Interface language -> Русский (Russian) / English -> Save.
  Выбор сохраняется. Язык Roblox настраивается отдельно в разделе «Запуск».
  Имена аккаунтов, игр, наборов и заметки остаются как были.

ВХОД ЧЕРЕЗ БРАУЗЕР
  «Окно браузера» открывает компактное окно Roblox в установленном Chrome / Edge.
  Если компактный режим завершился с ошибкой, один раз пробуется обычное окно.
  Расширение и скачивание не нужны. Вход и капчу проходишь сам.
  AltHub использует отдельный профиль и получает только Roblox-куку через CDP
  на временном порту 127.0.0.1. Твой личный профиль браузера не читается.
  Это не инкогнито. Перевод страницы отключён только в профиле AltHub.
  Перед загрузкой Roblox удаляется старая локальная кука входа; при завершении
  AltHub пытается удалить и новую локальную копию, без серверного выхода Roblox.
  После ручного закрытия окна/сбоя финальная очистка может не выполниться;
  следующий вход очистит старую куку до загрузки страницы.
  Пока окно открыто, CDP-порт не защищён паролем от других локальных программ.
  При завершении AltHub закрывает только процессы своего профиля входа.
  Настройки -> Из браузера -> Браузер для входа: системный либо Chrome for Testing.
  Chrome for Testing необязателен; загрузка — только отдельной кнопкой и с согласием.
  Размер зависит от версии; прогресс показывает фактические байты.
  «Из своего браузера, по клавише» — другой способ: для него расширение нужно.

НАБОРЫ АККАУНТОВ
  Отметь нужные аккаунты -> Действия -> Собрать в набор; затем Назначить игру.
  При переходе в другой набор галочки сохраняются, включая скрытые аккаунты.
  Скрытый выбор виден в статусе и требует подтверждения массового действия.
  Действия -> Снять все отметки очищает весь выбор. Сценарий сохраняет разные игры.

ЗНАЧОК В ЧАСАХ
  Правый клик -> Выход завершает AltHub. Крестик при настройке «в часы»
  только скрывает окно. Кнопка сворачивания оставляет окно на панели задач.
  При смене языка или вида меню старое окно освобождает свой значок.
  Проверочные формы больше не создают значки; тестовые копии завершаются штатно.
  Старый неактивный значок после принудительного завершения может оставаться
  в кэше Windows до обновления трея.

ПОРЯДОК АККАУНТОВ
  Перетащи карточку на другую — они поменяются местами. Ctrl+Z отменяет обмен.
  Старые дубли порядка исправляются автоматически, новые аккаунты идут в конец.
  Ctrl+1…9 выбирает окно по текущему видимому списку, включая поиск и набор.

БАЛАНС ROBUX
  Нажми «Проверить входы»: баланс, Premium и дата регистрации обновятся
  в фоне. Баланс виден также в компактном режиме. Robux: — означает,
  что значение ещё не получено. При ошибке запроса прежнее значение остаётся.

ЦЕНТР ЗАПУСКА
  Ctrl+L или Действия -> Центр запуска. Пауза, отмена очереди, повтор ошибок,
  состояние окон и память процессов. Пауза действует между запусками.
  Отменённые аккаунты не вернутся по присмотру до ручного запуска или
  перезапуска менеджера.

СЦЕНАРИИ
  Отметь аккаунты, задай каждому игру, графику и звук. В разделе «Сценарии»
  нажми «Сохранить сценарий». Он запомнит индивидуальные настройки и раскладку.
  «Быстрая настройка» позволяет выбрать основу для крупного окна.

ТВИНКИ — СВЕРНУТЬ И ВЕРНУТЬ
  Во всех трёх меню: правый клик по Окна -> Основной аккаунт -> выбери основу.
  Кнопка «Твинки» сворачивает остальные отслеживаемые AltHub окна.
  Повторный клик возвращает прежние места и обычное/развёрнутое состояние.
  Уже свёрнутые окна остаются свёрнутыми; основа не меняется.
  Процессы не приостанавливаются. Уменьшение нагрузки CPU/GPU не гарантируется.

СОХРАННОСТЬ ВХОДОВ
  Новый accounts.dat проверяется до атомарной замены старого.
  Пять предыдущих зашифрованных копий: data\backups\accounts\.
  Запоздалый ответ старой проверки не заменяет уже обновлённый вход.
  Выйти на сайте Roblox или сменить пароль всё ещё может отозвать сессию.

ЕСЛИ НЕ РАБОТАЕТ МАКРОС
  Проверь, не ищет ли он точный заголовок «Roblox». Отключение переименования
  окон (RenameWindows) возвращает исходный заголовок. Проверь конфликт клавиш
  с Ctrl+1…9 и клавишей моста браузера, а также уровни прав макроса и игры.
  Не запускай всё от администратора автоматически. Без конкретного AHK-скрипта
  нельзя подтвердить его совместимость или причину сбоя.

ПРОВЕРКИ
  Проверки\Самопроверка.ps1: ожидаемый итог «Пройдено 111 из 111».
  Результат проверки конкретного архива смотри в описании релиза.
  Авторизация Roblox, капча и большой живой набор клиентов требуют отдельной
  проверки. Успех локальных тестов не гарантирует работу каждого макроса.

ЕСЛИ НЕ ОТКРЫВАЕТСЯ
  Запусти «Проверки\Запустить с окном.cmd» — останется окно с точной
  причиной. Пришли её автору вместе с файлом из data\logs.

ЧТО ГДЕ ЛЕЖИТ
  AltHub.ps1, AltHub.vbs  — сама программа
  modules\                — её части; UiModern, UiPulse и modules\menus — виды меню
  modules\Localization.ps1, modules\locales\ — русский / English
  extension\              — расширение для входа из своего браузера
  Проверки\               — самопроверка и диагностика, для любопытных
  docs\, docs\en\          — снимки RU/EN на выдуманных аккаунтах
  data\                   — появится после первого запуска: ТВОИ аккаунты
                            и настройки. Никому не пересылай эту папку:
                            кто её получит, войдёт в твои аккаунты.

Внутри нет ни одного .exe — только текстовые файлы, открой любой Блокнотом.
Подробности — в README.md.
